# Проверочный контракт ORGANISM PWA TEST v0.1

Основа:
- event → action → result → verification → experience
- experience имеет type, confidence и applicability
- память адресуется логическими ID
- связи отдельны от содержимого
- контекст собирается перед вызовом агента
- опыт переносим между проектами условно, а не как жёсткий запрет
- импорт является источником/кандидатом, а не автоматической истиной
- UI показывает внутренний контекст и происхождение данных
- агент подключается через Model Adapter-подобный интерфейс
- прототип предназначен для проверки поведения на телефоне

Контроль:
1. Оболочка
2. Чат
3. Подключение агента
4. Импорт TXT
5. Отсев
6. Опыт +/-/mixed
7. Адреса
8. Многомерные атрибуты
9. Связи
10. Context Snapshot
11. Межпроектный поиск опыта
12. Экспорт/резервная копия
