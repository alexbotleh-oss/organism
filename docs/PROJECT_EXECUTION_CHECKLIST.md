- [~] **Частично** — реализована часть сценария, но есть незакрытые условия.

## Блокирующие причины, по которым сейчас нельзя заявить «готово»

1. Нет подтверждённой проверки интерфейса и функций на Android-устройстве.
2. Пользователь сообщает, что не видит ожидаемые настройки/экспорт и считает, что часть инструментов потеряна; это нужно воспроизвести и устранить.
3. Визуальная система не соответствует ожидаемому современному мобильному интерфейсу.
4. Семантический extractor полного цикла не реализован.
5. Повторный импорт, восстановление backup, миграции и отдельные session ID не подтверждены.
6. Полная сверка дерева функций с фактическим приложением ещё не завершена.
