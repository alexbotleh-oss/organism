# ORGANISM PWA TEST v0.1

Это мобильный HTML/PWA-прототип для проверки утверждённой концепции Организма.

## Запуск
Содержимое `web/` можно разместить на HTTPS-хостинге и открыть на Android в Chrome → «Добавить на главный экран».

## Что проверяет v0.1
- мобильная оболочка;
- проекты и чат;
- встроенный offline-тестовый агент;
- подключение OpenAI-совместимого агента;
- импорт TXT;
- первичный отсев кандидатов опыта;
- положительный/отрицательный/смешанный опыт;
- адресные ID и связи;
- Context Snapshot;
- экспорт локальной базы JSON.

## Важно
Это экспериментальный поведенческий прототип. Он пока не является полной реализацией backend-архитектуры ORGANISM_SOLUTION_v0.2: SQLite/FTS5, полноценные extraction/applicability/reinforcement/change-log и другие backend-компоненты будут следующим этапом.

API key для реального агента в этом прототипе хранится в localStorage; в полноценном приложении ключ должен находиться на защищённой стороне backend.

## Главный тест
TXT истории → импорт → опыт → база знаний → новый чат → Context Snapshot → агент → результат.


## ChatGPT bridge — экспериментальный режим

Для проверки целевого цикла Организма добавлен локальный мост официального Sign in with ChatGPT OSS-flow:

**Я → Организм → GPT → Организм → Я**

Запуск:

    python -m pip install -r requirements.txt
    python organism_server.py

Открыть в браузере: http://127.0.0.1:1455/

В настройках нажать «Подключить ChatGPT» и разрешить использование ChatGPT plan. API key для этого режима не нужен. OAuth-учётные данные сохраняются локально в пользовательской папке и не должны попадать в Git.

Текущий разговор хранится Организмом: сообщение пользователя и ответ GPT проходят через его интерфейс и могут становиться кандидатами нового опыта/знаний. История старых чатов по-прежнему импортируется отдельно.

Это экспериментальный мост, а не завершённая production-версия.
